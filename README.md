## 功能

| 功能 | 说明 |
| --- | --- |
| **解压** | 支持40+种格式，全部在本地完成解压 |
| **压缩** | 支持压缩文件为ZIP、RAR、7Z格式，全部在本地完成压缩 |
| **快速操作** | 支持把压缩文件拖到快捷方式进行解压缩 |
| **设置系统** | 性能设置与个性化选项 |
| **Windows桌面体验** | 专注于桌面环境下的日常使用 |

## 下载

前往 **[GitHub Releases](../../releases)** 页面获取最新版本。

1. 打开 Releases 页面，下载最新版本的安装程序。
2. 运行安装程序，并按照安装向导完成安装。
3. 启动 OmniUnzip，开始使用。

> **安全提示**
>
> 如果 Windows 显示“未知发布者”或 SmartScreen 安全警告，请先确认安装包来自本项目可信的官方发布渠道，再决定是否运行。
